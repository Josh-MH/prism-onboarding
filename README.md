# Prism Onboarding

Public setup site for Prism displays: https://josh-mh.github.io/prism-onboarding/

The [agent guide](agent-guide.txt) walks a new Grok Bot or Claude user through MCP OAuth, skill setup, physical TV pairing, optional presence, a sample card, and a daily claim routine. The [full skill](skills/prism-display/SKILL.md) is published here as readable source, and `prism-display-skill.zip` is packaged for Claude's skill upload flow.

The [clean-slate pilot checklist](pilot-test.md) gives expected observations for the authorized QM32C test.

`share/index.html` preserves Prism's one-use Chrome screen-sharing sender. Its invitations are generated by the Prism MCP and are never stored in this repository.

The Samsung TV app is maintained in the private Prism repository. `tv/pilot/` hosts the 2.0.64 signed package and `sssp_config.xml` for the already-authorized QM32C pilot display. Its Custom App URL is https://josh-mh.github.io/prism-onboarding/tv/pilot/ . Physical Custom App installation is still unverified. A general customer installer requires a production/B2B signing path; do not offer this DUID-limited package as a universal installer.
