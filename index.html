01 — The display

02 / 04

Begin at the screen.

Prism currently targets Samsung Tizen 7.0 or later. On first launch, it shows a pairing code in the lower right. If the screen says OFFLINE, check network access and registration before pairing.

Pilot installation

The available signed build is limited to approved device IDs. A general installer for new customer TVs still needs Samsung production/B2B signing and physical validation.

For Josh Hamil’s and Joe Burrage’s authorized Office TVs, enter this folder URL in Samsung Custom App / URL Launcher:

https://josh-mh.github.io/prism-onboarding/tv/pilot/

Use the folder URL, including the trailing slash. This onboarding page is not the TV install URL. Verify the version shown on each TV after installation.
