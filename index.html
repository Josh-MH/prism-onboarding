The first display

Three steps

1

Install the TV app

Connect a compatible Samsung signage display to the internet. The signed Prism app registers itself and shows a pairing code.

2

Connect your agent

Add Prism as a remote MCP connector in Grok or Claude. Complete Prism's anonymous OAuth connection page.

3

Pair and personalize

Give the on-screen code to your agent. For a new TV, set its name, location, weather ZIP, and space type.

Samsung signage

Prepare the TV

Prism currently targets Samsung Tizen 7.0 or later. Set the TV's local clock and time zone and give it internet access. On first launch it shows a five-minute code in the lower right.

Installer status: The available build uses a pilot distributor certificate tied to approved device IDs. A general Custom App URL for new customer TVs still needs Samsung production/B2B signing and a physical install test. This onboarding page is not the TV's Custom App URL.

For the already-authorized QM32C pilot TV, enter this exact folder URL in Samsung Custom App / URL Launcher settings:

https://josh-mh.github.io/prism-onboarding/tv/pilot/

The pilot installer has not yet been tested through Custom App on the physical TV. Other TVs need an installer approved for their device ID. If Prism shows OFFLINE rather than a code, fix network or registration before pairing.
